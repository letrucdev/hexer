Hexer @VERSION@

A hex editor for macOS. Open files, disks and firmware images of any size, and inspect, search, compare and edit them byte by byte.

Requirements

  • macOS 15 Sequoia or later.
  • A Mac with Apple silicon or an Intel processor.

Install

  1. In the window of this disk image, drag Hexer onto the Applications folder.
  2. Eject the disk image: in the Finder sidebar, click the eject button next to Hexer @VERSION@.

Open Hexer for the first time

Hexer is not notarized by Apple, so macOS blocks it the first time you open it. You allow it once; after that it opens normally.

  1. Open the Applications folder and double-click Hexer. macOS shows “Hexer” Not Opened. Click Done (not Move to Trash).
  2. Open System Settings ▸ Privacy & Security. Scroll down to Security. Next to “Hexer” was blocked to protect your Mac, click Open Anyway.
  3. In the dialog that follows, click Open Anyway again and confirm with your password or Touch ID.

If you are comfortable with Terminal, this command does the same in one step:
xattr -dr com.apple.quarantine /Applications/Hexer.app

Getting started

  • Open a file: File ▸ Open (⌘O), or drop the file onto Hexer in the Dock
  • Edit bytes: Type hex digits in the hex column; Tab switches to the text column. Changed bytes turn red until you save (⌘S).
  • Insert or overwrite: ⌘I, or the Insert / Overwrite / Read-only control in the toolbar
  • Undo, redo: ⌘Z, ⇧⌘Z (unlimited)
  • Find, replace: ⌘F, ⌥⌘F. Text, hex values, integers or floating point numbers. Find All lists every match.
  • Go to an offset: ⌘L
  • Select a block: ⇧⌘A
  • Bookmarks: ⌃⇧0–9 to set, ⌃0–9 to jump
  • Data inspector: ⌥⌘I. Shows the bytes at the caret as integers, floats, dates, GUIDs and disassembly; double-click a value to edit it.
  • Checksums: Analysis ▸ Checksums (⇧⌘K): CRC, MD5, SHA-1, SHA-256 and more
  • Compare two files: Analysis ▸ Compare (⌘K); F6 and ⇧F6 step through the differences
  • Byte statistics: Analysis ▸ Statistics
  • Firmware files: File ▸ Import: Intel Hex, Motorola S-Record, ETL Extended. File ▸ Export writes them, and source code or HTML.
  • Settings: Hexer ▸ Settings (⌘,): font, bytes per row, text encoding, inspector types

Disks

  • File ▸ Open Disk (⌥⌘O) opens physical disks and volumes; File ▸ Open Disk Image opens image files.
  • Disks open read-only by default. Opening a disk may ask for an administrator password.
  • Writing to a disk can destroy its data. Hexer asks before it opens a disk for writing, never writes until you save, and never writes to the startup disk.

Language

Hexer is in English and Vietnamese and follows the language of macOS. To choose its language on its own, open System Settings ▸ General ▸ Language & Region, and under Applications add Hexer with the language you want.

Uninstall

Quit Hexer and drag it from Applications to the Trash. Its settings are in ~/Library/Preferences/com.nongdandev.hexer.plist.
